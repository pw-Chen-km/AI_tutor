# Stoichiometry & Mole Calculations

## Output Shape
- `## Given Data`: 提供化學式、莫耳量與單位。
- `## Required`: 指定待求物質量。
- `## Answer`: 列出計算結果。
- `## Rationale`: 點出配平與比例關係。

## Example

```markdown
## Given Data
- Balanced equation: 2H2 + O2 -> 2H2O
- H2: 4.0 mol

## Required
Find moles of H2O formed with excess O2.

## Answer
4.0 mol H2O

## Rationale
Stoichiometric ratio H2:H2O is 1:1 in the balanced equation.
```

## Constraints
- 公式與符號需前後一致。
- 最終答案需可由題幹資訊直接推得。
