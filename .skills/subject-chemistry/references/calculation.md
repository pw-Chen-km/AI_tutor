# Chemistry Calculations (pH, equilibrium, thermochemistry)

## Output Shape
- `## Given Data`: 列出已知量與單位。
- `## Required`: 明確要求計算目標。
- `## Answer`: 提供最終數值與單位。
- `## Rationale`: 簡述核心公式或步驟。

## Example

```markdown
## Given Data
- Mass: 2.0 kg
- Acceleration: 3.0 m/s^2

## Required
Compute force.

## Answer
6.0 N

## Rationale
F = ma = 2.0 * 3.0 = 6.0 N.
```

## Constraints
- 公式與符號需前後一致。
- 最終答案需可由題幹資訊直接推得。
