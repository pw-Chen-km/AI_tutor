# Physics Derivations

## Output Shape
- `## Problem`: 指明待推導式子或關係。
- `## Assumptions`: 列出使用前提。
- `## Answer`: 給出推導結果。
- `## Rationale`: 2-4 行展示關鍵推導節點。

## Example

```markdown
## Problem
Derive the sum of the first n odd numbers.

## Assumptions
Use induction on n.

## Answer
1 + 3 + ... + (2n-1) = n^2

## Rationale
Base n=1 holds; inductive step adds 2k+1 to k^2 to obtain (k+1)^2.
```

## Constraints
- 公式與符號需前後一致。
- 最終答案需可由題幹資訊直接推得。
