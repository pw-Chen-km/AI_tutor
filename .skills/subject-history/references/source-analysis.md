# Primary & Secondary Source Analysis

## Output Shape
- `## Source`: 引用史料片段。
- `## Question`: 要求立場、目的或可信度判讀。
- `## Answer`: 給出判讀結論。
- `## Rationale`: 引用文本證據支持。

## Example

```markdown
## Source
> We must centralize authority to restore order.

## Question
What governing priority does this statement reveal?

## Answer
Preference for stability through stronger central control.

## Rationale
The source explicitly links order to concentration of authority.
```
