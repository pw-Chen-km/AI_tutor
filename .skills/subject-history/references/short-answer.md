# Short Answer (History)

## Output Shape
- `## Question`: 單句提問，鎖定一個核心重點。
- `## Expected Points`: 2-4 個關鍵得分點。
- `## Answer`: 2-5 句精簡作答。
- `## Scoring`: 關鍵點對應配分。

## Example

```markdown
## Question
State one cause and one consequence of rapid urbanization.

## Expected Points
- Cause: rural-to-urban migration
- Consequence: housing pressure

## Answer
A common cause is migration for jobs. One consequence is increased housing demand and rising rents.

## Scoring
- Cause identified: 1
- Consequence identified: 1
```
