# Generic Proof / Justification

## Output Shape
- `## Claim`: 明確待證命題。
- `## Method`: 指定證明法（直接、反證、歸納等）。
- `## Answer`: 完整但精簡的證明主幹。
- `## Rationale`: 點出最關鍵一步。

## Example

```markdown
## Claim
If n is even, then n^2 is even.

## Method
Direct proof.

## Answer
Let n=2k. Then n^2=4k^2=2(2k^2), so n^2 is even.

## Rationale
Evenness is preserved under multiplication by 2.
```

## Constraints
- 公式與符號需前後一致。
- 最終答案需可由題幹資訊直接推得。
