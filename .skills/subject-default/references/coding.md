# Coding (Generic)

## Output Shape
- `## Task`: 指定要實作的函式/方法。
- `## Signature`: 輸入輸出型別與回傳規則。
- `## Code`: 範例 I/O 或測試呼叫。
- `## Constraints`: 邊界條件與錯誤處理。

## Example

````markdown
## Task
Implement `max_gap(nums: list[int]) -> int` to return the largest adjacent difference after sorting.

## Signature
Input: list[int], Output: int

## Code
```python
max_gap([3, 10, 6])  # 4
```

## Constraints
Return 0 when input has fewer than 2 elements.
````
