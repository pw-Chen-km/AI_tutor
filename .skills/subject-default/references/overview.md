# Generic Subject — Overview

## Output Shape
- `## Prompt`: 清楚交代任務。
- `## Required`: 說明作答輸出格式。
- `## Answer`: 提供標準答案。
- `## Rationale`: 1-2 句說明依據。

## Example

```markdown
## Prompt
State one cause of the event and one consequence.

## Answer
Cause: prolonged drought. Consequence: reduced crop output.

## Rationale
The source links water shortage to lower agricultural yield.
```
