# Pathway Questions (Biology)

## Output Shape
- `## Prompt`: 指定生物流程或路徑。
- `## Required`: 要求排序、定位或功能判讀。
- `## Answer`: 提供正確流程節點。
- `## Rationale`: 說明上下游關係。

## Example

```markdown
## Prompt
Arrange aerobic respiration stages in order.

## Required
List the sequence from glucose to ATP generation.

## Answer
Glycolysis -> Pyruvate oxidation -> Citric acid cycle -> Oxidative phosphorylation

## Rationale
Each stage feeds substrates or reducing equivalents to the next stage.
```
