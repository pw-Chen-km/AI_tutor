# Data Analysis (Geography)

## Output Shape
- `## Data`: 表格或數據摘要（含欄位意義）。
- `## Question`: 指定比較、解讀或推論任務。
- `## Answer`: 明確結論（可含數值）。
- `## Rationale`: 依據數據說明推理路徑。

## Example

```markdown
## Data
| Year | Output |
|------|--------|
| 2023 | 95     |
| 2024 | 110    |

## Question
Calculate growth rate from 2023 to 2024.

## Answer
Growth rate is 15.8%.

## Rationale
(110-95)/95 = 0.1579, rounded to 15.8%.
```
