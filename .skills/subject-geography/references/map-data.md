# Maps, Data & Spatial Patterns

## Output Shape
- `## Map/Data`: 提供地圖符號或資料摘要。
- `## Question`: 要求空間分布解讀。
- `## Answer`: 給出區位或趨勢判斷。
- `## Rationale`: 對應圖例與數據。

## Example

```markdown
## Map/Data
Population density is highest along the eastern coastline and lowest in inland plateaus.

## Question
Which direction shows the steepest density decline?

## Answer
From east to west.

## Rationale
The map description indicates a clear coastal-to-inland gradient.
```
